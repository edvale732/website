# Personal Portfolio Website

### [Visit Website](www.edwardvale.co.uk)

### A minimal, clean personal portfolio website, showcasing my personal, university and client projects.

## Overview

A simple website with just two pages, home and projects

### Home Page

- The home page contains a hero statement, profile picture, links and a button to direct you to the projects page

### Projects Page

- This page is designed to show what projects I have been working on
- This is split into 4 sections, Featured, Personal, University and Client projects
- Projects are displayed in a grid, each with an image, title, description and tags
- The project card can be clicked to view more details on the individual project page
- The individual projects page pulls the README.md from the project's public GitHub repo, if it exists.
- If the README.md does not exist, the description is shown instead

## Stack

### Frontend

- Next.js
- React
- TypeScript
- TailwindCSS
